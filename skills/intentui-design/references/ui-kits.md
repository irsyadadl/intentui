# UI kits

Discover available UI kits through the official product/account catalog and verify the user's entitlement. Inspect the documented format, framework, assets, and installation instructions. A Figma/design download, source archive, repository entitlement, or UI kit is not automatically installable with shadcn add.

Use the documented authorized download/import workflow and map its design primitives to the consuming project's installed v4 APIs. Do not imply kits are free, invent product URLs, or redistribute assets through this skill. If current kit installation instructions are not available, report that gap rather than supply a speculative command. [Official product catalog](https://design.intentui.com).

Design resources target v4 only. Verify the selected resource against local v4 exports/tokens; flag stale v3 payloads instead of producing a v3 variant. For registry-installable resources @irsyad includes public component dependencies, so do not require a duplicate @intentui namespace. Formats requiring downloads retain their separate authorized workflow.
