## What's new

- Upgraded to Tailwind CSS v4.
- Changed the color format to OKLCH to match Tailwind CSS v4.
- Removed TRAC.
- Redesigned every component.
- Removed the `accent-subtle`, `accent-subtle-fg`, `tertiary`, and `tertiary-fg` color tokens.
- Added the `sidebar`, `sidebar-fg`, `navbar`, and `navbar-fg` color tokens.
- Added the `chart-1`, `chart-2`, `chart-3`, `chart-4`, and `chart-5` color tokens.
- Calendar and Range Calendar now use `rounded-lg` instead of `rounded-full` by default.
- Some existing components, such as [Chart](/docs/components/charts/setup), [Sidebar](/docs/components/layouts/sidebar), [Disclosure](/docs/components/navigation/disclosure), and [TagGroup](/docs/components/collections/tag-group), no longer use the [compound component pattern](https://www.patterns.dev/react/compound-pattern/).
- Added the [Blocks](/blocks) page.
- Moved Grid to alpha and removed its collections support.
- Moved `cn()` to `utils/classes.ts`.
- Moved `useMediaQuery` to `utils/use-media-query.ts`.
- Pagination now uses the `segment` prop instead of `variant`.
- Added `visibleDuration` support to [Date Range Picker](/date-range-picker) and [Range Calendar](/range-calendar).
- Rewrote the following components:
  - Sidebar
  - Disclosure
  - Navbar
  - Button
  - Field

## Pages

This release adds Blocks and updates the Themes and Colors pages.

### Blocks

The [Blocks page](/blocks) provides examples of layouts built with components such as Sidebar and Navbar.

### Themes

Use the [Themes page](https://design.intentui.com/themes) to build custom themes.

### Colors

The [Colors page](/colors) now uses OKLCH to match Tailwind CSS v4.

## CLI

The CLI also supports Tailwind CSS v3 projects. It detects the project type and installs the required packages.
