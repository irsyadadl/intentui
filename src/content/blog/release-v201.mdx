## What's new

- **Dependencies**: Upgraded React Aria Components to v1.6.0.
- **Command Menu**: Integrated Autocomplete from React Aria Components.
    - Renamed `CommandMenuInput` to `CommandMenuSearch`.
    - Added `CommandMenuLabel`.

- **Dropdown labels**: Items with icons or avatars now require labels.

- **Menu**:
    - Added `MenuLabel`.
    - Removed `MenuCheckbox` and `MenuRadio`.

- **Sidebar**:
    - Added `Sidebar.Label`.
    - Added shortcut props for collapsing the sidebar.
