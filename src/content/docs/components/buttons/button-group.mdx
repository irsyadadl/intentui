## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/button-group"/>

## Manual installation

Install the dependencies, then copy the component source into your project.

<PackageCommand command="npm i tailwind-variants cn"/>

<SourceCode toShow='button-group'/>

## Anatomy
```
import { ButtonGroup } from "@/components/ui/button-group";
import { Button } from "@/components/ui/button";
```

```
<ButtonGroup>
  <Button/>
</ButtonGroup>
```
