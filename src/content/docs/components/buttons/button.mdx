## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/button"/>

## Manual installation

Install the dependencies, then copy the component source into your project.

<PackageCommand command="npm i react-aria-components tailwind-variants"/>

## Anatomy
```
import { Button } from "@/components/ui/button"
import { Cog6ToothIcon } from "@heroicons/react"
```

  <Button intent="warning">Warning</Button>
  <Button intent="danger">Danger</Button>

## Examples

### Intent
Use `intent` to choose the button’s color scheme.

<How toUse="buttons/button/button-intent-example" />

### Shape
Use `isCircle` to make the button circular.

<How toUse="buttons/button/button-shape-example" />

### Size
Use `size` to set the button size.

<How toUse="buttons/button/button-size-example" />

### With icon
You can add icons to buttons, and their color will match the button's color.

<How toUse="buttons/button/button-icon-example" />

### Disabled
Set `isDisabled` to prevent interaction with the button.

<How toUse="buttons/button/button-disabled-example" />

### Pending
A button can indicate a pending state using the `isPending` prop. This provides feedback for actions that take time, communicates the status to assistive technologies, and disables interactions except for focus.

<How toUse="buttons/button/button-pending-example" />

### With loader
You can add a loader to indicate ongoing processes.

<How toUse="buttons/button/button-loader-example" />

### Link
Apply `buttonStyles` to a link’s `className` to style it as a button.
<How toUse="buttons/button/button-link-example" />

### Render
You can render a [Motion](https://motion.dev/) button and drive the animation with component state.
<How toUse="buttons/button/button-render-example" />

## Touch hitbox
For icon-only buttons, use a `sq-*` size and the `touch-target` utility to increase the interactive area.
```css
@utility touch-target {
  position: relative;
  &::before {
    content: "";
    position: absolute;
    display: block;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
    width: 100%;
    height: 100%;
    min-height: 44px;
    min-width: 44px;
    z-index: 9999;
  }
}
```
