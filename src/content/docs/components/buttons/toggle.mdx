## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/toggle"/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components tailwind-variants cn"/>
<SourceCode toShow='toggle'/>

## Touch target
Add the following utility to your global CSS file to ensure interactive elements have a minimum touch target of 44 × 44 pixels without changing their visual size.
```css
@utility touch-target {
  position: relative;
  &::before {
    content: "";
    position: absolute;
    display: block;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
    width: 100%;
    height: 100%;
    min-height: 44px;
    min-width: 44px;
    z-index: 9999;
  }
}
```

<Note intent="default">
    This utility is automatically included when installing the Toggle component via the CLI. You only need to add it for manual installations.
</Note>
