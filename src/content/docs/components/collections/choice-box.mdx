## Anatomy
```
import {
  ChoiceBox,
  ChoiceBoxDescription,
  ChoiceBoxItem,
  ChoiceBoxLabel,
} from '@/components/ui/choice-box'
```

```
<ChoiceBox aria-label="Select items" selectionMode="multiple">
  <ChoiceBoxItem textValue="premium">
    <ChoiceBoxLabel>Premium</ChoiceBoxLabel>
    <ChoiceBoxDescription>Advanced options for growing needs.</ChoiceBoxDescription>
  </ChoiceBoxItem>
  <ChoiceBoxItem textValue="deluxe">
    <ChoiceBoxLabel>Deluxe</ChoiceBoxLabel>
    <ChoiceBoxDescription>Top-tier features for maximum performance.</ChoiceBoxDescription>
  </ChoiceBoxItem>
  <ChoiceBoxItem textValue="ultimate">
    <ChoiceBoxLabel>Ultimate</ChoiceBoxLabel>
    <ChoiceBoxDescription>
      All-inclusive plan with every feature available.
    </ChoiceBoxDescription>
  </ChoiceBoxItem>
  <ChoiceBoxItem textValue="enterprise">
    <ChoiceBoxLabel>Enterprise</ChoiceBoxLabel>
    <ChoiceBoxDescription>Customized solutions for large organizations.</ChoiceBoxDescription>
  </ChoiceBoxItem>
</ChoiceBox>
```

## Examples

### Multiple selection
Choice boxes use single selection by default. Set `selectionMode="multiple"` to allow multiple selections.

<How toUse="collections/choicebox/choicebox-multiple-selection-example" />

### Columns and gap
By default, the gap between items is set to `0`, and the `columns` prop is also `0`. You can customize both by providing your own `gap` and `columns` values.
<How isCenter={false} withNoPadding={true} toUse="collections/choicebox/choicebox-columns-example" />

### Icons
Add icons to choice box items with the `icon` prop.
<How toUse="collections/choicebox/choicebox-icon-example" />

### Controlled
For controlled selection, pass `selectedKeys` and update it with `onSelectionChange`.
<How toUse="collections/choicebox/choicebox-controlled-example" />

### Disabled
Set `isDisabled` to disable the entire choice box.
<How withNoPadding={true} toUse="collections/choicebox/choicebox-disabled-example" />

Individual items can also be disabled by specifying their keys in the `disabledKeys` prop.

```tsx
<Choicebox disabledKeys={['sm', 'lg']} />
```
