<Composed components={['dropdown']}/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components @heroicons/react cn"/>

<SourceCode toShow='list-box'/>

## Anatomy
```
import { ListBox, ListBoxItem } from "@/components/ui/list-box"
```

```
<ListBox aria-label="Bands">
  <ListBoxItem>Nirvana</ListBoxItem>
  <ListBoxItem>Radiohead</ListBoxItem>
  <ListBoxItem>Foo Fighters</ListBoxItem>
  <ListBoxItem>Arctic Monkeys</ListBoxItem>
  <ListBoxItem>The Strokes</ListBoxItem>
</ListBox>
```

## Examples

### Multiple selection
Set `selectionMode="multiple"` to allow multiple selections.
<How toUse="collections/list-box/list-box-multiple-example" />

### Description
Add supporting text with `ListBoxDescription`.
<How toUse="collections/list-box/list-box-description-example" />

### Section
Group items in a ListBox using sections for better organization.
<How toUse="collections/list-box/list-box-section-example" />

### Drag and drop
Enable drag-and-drop functionality in the ListBox by using the `dragAndDropHooks` prop with the `useDragAndDrop` hook. This allows users to rearrange items, insert new entries, or manage data across the list.
<How toUse="collections/list-box/list-box-rearrange-example" />

### Infinite scrolling
Load more items as users scroll with infinite scrolling.
<How toUse="collections/list-box/list-box-infinite-scroll-example" />

### Controlled
For controlled selection, pass `selectedKeys` and update it with `onSelectionChange`. Set `selectionMode="single"` to allow one selected item.
<How toUse="collections/list-box/list-box-controlled-example" />

### Disabled
Disable specific ListBox items to restrict user interaction.
<How toUse="collections/list-box/list-box-disabled-example" />

You can also disable an item directly by passing the `isDisabled` prop to `ListBoxItem`.

```tsx
<ListBoxItem isDisabled>Disabled</ListBoxItem>
```
