## Examples

### Multiple selection
Set `selectionMode="multiple"` to allow multiple selections.
<How toUse="collections/tree/tree-multiple-example" />

### Like a folder tree
A tree can be used to represent a folder structure, allowing users to expand and collapse folders to view their contents.
<How toUse="collections/tree/tree-folder-example" />

### Infinite scrolling
Load more tree items as users scroll with infinite scrolling.
<How toUse="collections/tree/tree-infinite-scroll-example" />

### Drag and drop
The tree supports drag and drop functionalities if you use the `dragAndDropHooks` prop along with the `useDragAndDrop` hook. You can drop data on the entire tree, individual items, add new items between existing ones, or rearrange items.
<How toUse="collections/tree/tree-drag-example" />
