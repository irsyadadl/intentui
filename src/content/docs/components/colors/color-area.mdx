## Examples

### Channel
Specify the color channels for the horizontal and vertical axes using the `xChannel` and `yChannel` properties.
<How toUse="colors/color-area/color-area-channel-example" />

### Space
Set `colorSpace` to `rgb`, `hsl`, or `hsb`. Choose `xChannel` and `yChannel` values that belong to that color space.
<How toUse="colors/color-area/color-area-space-example" />

### Controlled
Pass `value` and update it with `onChange` to control the selected color.
<How toUse="colors/color-area/color-area-controlled-example" />

### Disabled
Set `isDisabled` on the color area to disable interaction.
<How toUse="colors/color-area/color-area-disabled-example" />

### Color area with slider
Combine a color area with a slider to adjust different channels of the same color.
<How toUse="colors/color-area/color-area-with-slider-example" />
