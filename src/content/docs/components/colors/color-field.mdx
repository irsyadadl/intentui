<PackageCommand command="npx shadcn@latest add @intentui/color-field"/>

## Composed components
<Composed components={['field', 'color-swatch', 'color-picker']}/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components"/>
<SourceCode toShow='color-field'/>

## Anatomy
```
import { ColorField } from "@/components/ui/color-field"
import { Label, Description } from "@/components/ui/field"
import { Input } from "@/components/ui/input"
```
```
<ColorField>
  <Label/>
  <Input/>
  <Description/>
</ColorField>
```
