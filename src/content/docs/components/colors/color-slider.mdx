<Composed components={['field']}/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components"/>
<SourceCode toShow='color-slider'/>

## Anatomy
```
import { ColorSlider } from "@/components/ui/color-slider"

<ColorSlider channel="hue" />
```

## Examples

### With label
Add a label to identify the color channel.
<How minW60 toUse="colors/color-slider/color-slider-with-label-example" />

### Orientation
By default, the color slider is horizontal. You can change it to vertical by setting the `orientation` prop to `vertical`.
<How minW60 toUse="colors/color-slider/color-slider-vertical-example" />

### Controlled
Pass `value` and update it with `onChange` to control the color slider.
<How minW60 toUse="colors/color-slider/color-slider-controlled-example" />

### Disabled
Disable interaction with the color slider using the `isDisabled` prop.
<How minW60 toUse="colors/color-slider/color-slider-disabled-example" />
