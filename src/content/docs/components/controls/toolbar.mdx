## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/toolbar"/>

## Composed components
<Composed components={['toggle', 'separator']}/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components cn"/>

<SourceCode toShow='toolbar'/>

## Anatomy
```
import { Toolbar, ToolbarGroup, ToolbarItem, ToolbarSeparator } from "@/components/ui/toolbar"
```
```
<Toolbar>
  <ToolbarGroup>
    <ToolbarItem />
    <ToolbarItem />
    <ToolbarItem />
  </ToolbarGroup>
  <ToolbarSeparator />
  <ToolbarGroup>
    <ToolbarItem />
  </ToolbarGroup>
</Toolbar>
```

## Examples

### Orientation
By default, the toolbar is displayed horizontally. You can change it to vertical using the `orientation` prop.
<How toUse="controls/toolbar/toolbar-orientation-example" />

### Disabled
You can disable a toolbar either as a group or individually by using the `isDisabled` prop.
<How toUse="controls/toolbar/toolbar-disabled-example" />
