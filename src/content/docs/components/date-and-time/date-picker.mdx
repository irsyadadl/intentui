## Examples

### Date and time
While not a full-fledged date-time picker, this setup lets you edit both date and time in a segmented field.
<How minW60 toUse="date-and-time/date-picker/date-time-example" />

### Validation
Set `isRequired` to require a date when the form is submitted.
<How minW60 toUse="date-and-time/date-picker/date-picker-required-example" />

### Custom validation
Use `validate` to check the date and return an error message or an array of messages for invalid values.
<How minW60 toUse="date-and-time/date-picker/date-picker-custom-validation-example" />

### Controlled
Pass `value` and update it with `onChange` to control the selected date.
<How minW60 toUse="date-and-time/date-picker/date-picker-controlled-example" />

### Disabled
When the date picker is disabled, it becomes non-interactive and visually represents a disabled state.
