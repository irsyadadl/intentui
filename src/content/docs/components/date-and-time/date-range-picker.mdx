## Examples

### Validation
Set `isRequired` to require a date range when the form is submitted.
<How className="min-w-[17rem]" toUse="date-and-time/date-range-picker/date-range-picker-validation-example" />

### Custom validation
Use the `validate` function to implement custom validation rules. It evaluates the current date range and returns error messages if the value doesn't meet your criteria.
<How className="min-w-[17rem]" toUse="date-and-time/date-range-picker/date-range-picker-custom-validation-example" />

### Visible duration
Set `visibleDuration` to choose how much of the calendar is visible. It accepts an object with these duration units:
* `years`: The number of years to display.
* `months`: The number of months to display.
* `weeks`: The number of weeks to display.
* `days`: The number of days to display.

See <NewTab href="https://react-aria.adobe.com/RangeCalendar.html#multi-month">visible duration in React Aria</NewTab> for details.

<How className="min-w-[17rem]" toUse="date-and-time/date-range-picker/date-range-picker-visible-duration-example" />

### Controlled
Pass `value` and update it with `onChange` to control the selected date range.

### Disabled
When the date range picker is disabled, it becomes non-interactive and is visually represented in a disabled state.
