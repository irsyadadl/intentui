## Examples

### Hour cycles
Change the hour format in the time field by using the `hourCycle` prop.
<How toUse="date-and-time/time-field/time-field-hc-example" />

### Validation
Set `isRequired` to require a time when the form is submitted.
<How toUse="date-and-time/time-field/time-field-validation-example" />

### Controlled
Pass `value` and update it with `onChange` to control the time field.
<How toUse="date-and-time/time-field/time-field-controlled-example" />

### Readonly
Set `isReadOnly` to prevent edits while keeping the time field focusable.
<How toUse="date-and-time/time-field/time-field-readonly-example" />

### Disabled
A disabled time field cannot be interacted with and is visually represented as being inactive.
<How toUse="date-and-time/time-field/time-field-disabled-example" />
