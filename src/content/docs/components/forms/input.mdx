Install the dependencies, then copy the component source into your project.

## Anatomy
```
import { Input } from "@/components/ui/input";

<Input/>
```

## Examples

### Input group
Use `InputGroup` to add prefix or suffix content. Icons receive spacing automatically. For `Text` content, set `--input-gutter-start` or `--input-gutter-end` to reserve enough space on the corresponding side.

<How minW60 toUse="forms/input/input-group-example" />

### Label and description
Use a label to name the input and a description to provide instructions.

<How minW60 toUse="forms/input/input-label-description-example" />

### Text field
For a standalone input, match its `id` to the label’s `htmlFor`. `TextField` associates its label, input, and description automatically.

<How minW60 toUse="forms/input/input-text-field-example" />

You can learn more in the [TextField documentation](/docs/components/forms/text-field).

### Controlled
Pass `value` and update it with `onChange` to control the input.
<How minW60 toUse="forms/input/input-controlled-example" />
