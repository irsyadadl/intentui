## Manual installation

Install the dependencies, then copy the component source into your project.

<PackageCommand command="npm i react-aria-components @heroicons/react"/>

## Anatomy
```
import { NumberField, NumberInput } from "@/components/ui/number-field"
import { Label, Description, FieldError } from "@/components/ui/field"

<NumberField>
  <Label/>
  <NumberInput />
  <Description />
  <FieldError />
</NumberField>
```
