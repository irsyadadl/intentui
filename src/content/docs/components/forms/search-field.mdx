## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/search-field"/>

## Composed components
<Composed components={['field', 'input']}/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components @heroicons/react cn"/>

<SourceCode toShow='search-field'/>

## Anatomy
```
import { SearchField, SearchInput } from "@/components/ui/search-field"

<SearchField>
  <SearchInput placeholder="Search..." />
</SearchField>
```

## Examples

### With label
Add a `Label` inside `SearchField` to provide a visible label.
<How toUse="forms/search-field/search-field-with-label-example" />

### Validation
Set `isRequired` and include `FieldError` to display a validation message when the form is submitted without a value.
<How toUse="forms/search-field/search-field-validation-example" />

### Description
Add `Description` inside `SearchField` to provide supporting text.
<How toUse="forms/search-field/search-field-description-example" />

### Controlled
Pass `value` and update it with `onChange` to control the search query.
<How toUse="forms/search-field/search-field-controlled-example" />

### Uncontrolled
Use `defaultValue` to set the initial value of an uncontrolled field.
<How toUse="forms/search-field/search-field-uncontrolled-example" />

### Readonly
When the search field is set to readonly, it cannot be edited.
<How toUse="forms/search-field/search-field-readonly-example" />

### Disabled
Disable the search field by using the `isDisabled` prop.
