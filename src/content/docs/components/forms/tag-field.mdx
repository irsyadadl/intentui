To install, run the following command:

<PackageCommand command="npx shadcn@latest add @intentui/tag-field"/>

Install the dependencies, then copy the component source into your project.

For manual installation, use:

<PackageCommand command="npm i react-aria-components @heroicons/react cn"/>

## Anatomy
Import the components and use them as shown below, adapting the structure to fit each component.
```
import { Label } from "@/components/ui/field"
import { Input } from "@/components/ui/input"
import { TagField } from "@/components/ui/tag-field"
```

```
<TagField>
  <Label/>
  <Input/>
</TagField>
```
