Install the dependencies, then copy the component source into your project.

## Anatomy
```
import { Textarea } from "@/components/ui/textarea"

<Textarea
  label="Address"
  description="Please enter your address"
/>
```

### Description
You can add a description to the textarea by using the `description` prop.
<How minW60 toUse="forms/textarea/textarea-description-example" />


### Controlled
Pass `value` and update it with `onChange` to control the textarea.
<How minW60 toUse="forms/textarea/textarea-controlled-example" />

### Uncontrolled
Use `defaultValue` to set the initial text of an uncontrolled textarea.
<How minW60 toUse="forms/textarea/textarea-uncontrolled-example" />

### Validation
Try submitting the form without filling it out to see the error state in action.
<How minW60 toUse="forms/textarea/textarea-validation-example" />

### With autocomplete
You can add autocomplete to a textarea by wrapping it with the Autocomplete component. This is useful for tags, mentions, or similar input patterns.
<How minW60 toUse="forms/textarea/textarea-autocomplete-example" />

### Readonly
When the textarea is set to readonly, it cannot be edited.
<How minW60 toUse="forms/textarea/textarea-readonly-example" />

### Disabled
