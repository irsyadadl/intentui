Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/carousel"/>

## Composed components
<Composed components={['button']}/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components embla-carousel-react @heroicons/react cn"/>

<SourceCode toShow='carousel'/>

## Anatomy
```
import {
  Carousel,
  CarouselButton,
  CarouselContent,
  CarouselHandler,
  CarouselItem,
} from "@/components/ui/carousel"
```

```
<Carousel>
  <CarouselContent>
    <CarouselItem className="basis-1/2">Slide 1</CarouselItem>
    <CarouselItem className="basis-1/2">Slide 2</CarouselItem>
    <CarouselItem className="basis-1/2">Slide 3</CarouselItem>
  </CarouselContent>

  <CarouselHandler>
    <CarouselButton segment="previous" />
    <CarouselButton segment="next" />
  </CarouselHandler>
</Carousel>
```

## Examples

### Orientation
You can change the orientation of the carousel by using the `orientation` prop. The default is horizontal, but you can switch it to vertical.
<How minW60 toUse="media/carousel/carousel-orientation-example" />

### Options
Use `opts` to configure carousel behavior, including looping and alignment.
<How withNoPadding={false} toUse="media/carousel/carousel-options-example" />

### Autoplay
Install the Embla Carousel autoplay plugin to advance slides automatically.
<PackageCommand command="npm i embla-carousel-autoplay"/>

Pass the installed plugin through `plugins`.
<How minW60 toUse="media/carousel/carousel-autoplay-example" />

### Link
If you need a link in carousel item, it simple, add href to the CarouselItem.
```
<CarouselItem href="/path/to/page"/>
```
