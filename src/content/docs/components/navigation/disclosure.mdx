## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/disclosure-group"/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components @heroicons/react cn"/>

<SourceCode toShow='disclosure-group'/>

## Anatomy
```
import { Disclosure, DisclosurePanel, DisclosureTrigger } from "@/components/ui/disclosure-group";
```

```
<Disclosure>
  <DisclosureTrigger>
    Trigger
  </DisclosureTrigger>
  <DisclosurePanel>
    Content
  </DisclosurePanel>
</Disclosure>
```
