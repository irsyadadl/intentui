## Installation

Add the component with the CLI.
To install the required package, run the following command:

<PackageCommand command="npm i react-aria-components"/>

<SourceCode toShow='link'/>

## Anatomy
```
import { Link } from "@/components/ui/link"

<Link href="#basic">Label</Link>
```

## Client side routing
To use `Link` with your router’s link component, see [Client Side Routing](/docs/getting-started/client-side-routing).


## Examples

### Unstyled
Links are unstyled by default. Apply classes through `className`.
<How toUse="navigation/link/link-unstyled-example" />

### Use as button
Apply `buttonStyles` to the link’s `className` to style it as a button.
<How toUse="navigation/link/link-button-example" />

### Disabled
You can disable the link by setting the `isDisabled` prop.
<How toUse="navigation/link/link-disabled-example" />
