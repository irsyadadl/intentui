## Anatomy

`PopoverTrigger` wraps a `Button` and `Popover`. It manages the trigger interaction and open state, so you do not need to pass a button ref or manage state for an uncontrolled popover. `PopoverTrigger` is an alias of `DialogTrigger`.

```tsx
"use client"

import { Button } from "@/components/ui/button"
import {
  Popover,
  PopoverBody,
  PopoverDescription,
  PopoverFooter,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover"

export function Example() {
  return (
    <PopoverTrigger>
      <Button>Open popover</Button>
      <Popover aria-labelledby="" aria-label="Project details">
        <PopoverHeader>
          <PopoverTitle>Project details</PopoverTitle>
          <PopoverDescription>Review your project before continuing.</PopoverDescription>
        </PopoverHeader>
        <PopoverBody>Popover body</PopoverBody>
        <PopoverFooter>
          Review your project details before continuing.
        </PopoverFooter>
      </Popover>
    </PopoverTrigger>
  )
}
```

`PopoverTrigger` labels the popover from its opening button by default. To provide a separate `aria-label`, clear the inherited label with `aria-labelledby=""` as shown above.

`Popover` provides the dialog semantics itself. Do not wrap its content in the Intent UI `Dialog`, which creates a separate overlay.

## Examples

### Controlled
Pass `isOpen` and `onOpenChange` to `PopoverTrigger` to control the popover programmatically. Placement and appearance props stay on `Popover`.
<How toUse="overlays/popover/popover-controlled-example" />

### Overlay arrow
Popovers come with an arrow that points to the trigger element, but it’s hidden by default. To display it, pass the `arrow` prop.
<How toUse="overlays/popover/popover-arrow-example" />

### Placement
You can change the placement of the popover by passing the `placement` prop.
<How toUse="overlays/popover/popover-placement-example" />

The list above shows the primary directions, but you can also use specific placements like `bottom left` or `top right`. Here are all the available placement options:

| Primary Direction | Placement                                                             |
|-------------------|-----------------------------------------------------------------------|
| `bottom`          | `bottom`, `bottom left`, `bottom right`, `bottom start`, `bottom end` |
| `top`             | `top`, `top left`, `top right`, `top start`, `top end`                |
| `left`            | `left`, `left top`, `left bottom`                                     |
| `start`           | `start`, `start top`, `start bottom`                                  |
| `right`           | `right`, `right top`, `right bottom`                                  |
| `end`             | `end`, `end top`, `end bottom`                                        |


### Custom close
Use a button with `onPress={() => setIsOpen(false)}` to close a controlled popover. Escape and clicking outside also close it through `onOpenChange`.
<How toUse="overlays/popover/popover-custom-close" />

### Custom trigger

Place your custom button inside `PopoverTrigger`. For an avatar trigger, put `Avatar` inside `Button` and give the button an `aria-label`. The wrapper handles the trigger ref and ARIA state.

<How toUse="overlays/popover/popover-trigger-example" />
