## Anatomy

Use your own button as the trigger. Keep a ref to that button and pass it to `Popover` with `isOpen` and `onOpenChange`. The popover manages focus, Escape, and outside-click dismissal.

```tsx
"use client"

import { useRef, useState } from "react"
import { Button } from "@/components/ui/button"
import {
  Popover,
  PopoverBody,
  PopoverDescription,
  PopoverFooter,
  PopoverHeader,
  PopoverTitle,
} from "@/components/ui/popover"

export function Example() {
  const [isOpen, setIsOpen] = useState(false)
  const triggerRef = useRef<HTMLButtonElement>(null)

  return (
    <>
      <Button
        ref={triggerRef}
        aria-haspopup="dialog"
        aria-expanded={isOpen}
        onPress={() => setIsOpen(true)}
      >
        Open popover
      </Button>
      <Popover aria-label="Project details" triggerRef={triggerRef} isOpen={isOpen} onOpenChange={setIsOpen}>
        <PopoverHeader>
          <PopoverTitle>Project details</PopoverTitle>
          <PopoverDescription>Review your project before continuing.</PopoverDescription>
        </PopoverHeader>
        <PopoverBody>Popover body</PopoverBody>
        <PopoverFooter>
          <Button intent="plain" onPress={() => setIsOpen(false)}>Close</Button>
          <Button onPress={() => setIsOpen(false)}>Confirm</Button>
        </PopoverFooter>
      </Popover>
    </>
  )
}
```

`Popover` provides the dialog semantics itself. Do not wrap its content in the Intent UI `Dialog`, which creates a separate overlay.

### Controlled

### Overlay arrow
Popovers come with an arrow that points to the trigger element, but it’s hidden by default. To display it, pass the `arrow` prop.
<How toUse="overlays/popover/popover-arrow-example" />

### Placement
You can change the placement of the popover by passing the `placement` prop.
<How toUse="overlays/popover/popover-placement-example" />

The list above shows the primary directions, but you can also use specific placements like `bottom left` or `top right`. Here are all the available placement options:

| Primary Direction | Placement                                                             |
|-------------------|-----------------------------------------------------------------------|
| `bottom`          | `bottom`, `bottom left`, `bottom right`, `bottom start`, `bottom end` |
| `top`             | `top`, `top left`, `top right`, `top start`, `top end`                |
| `left`            | `left`, `left top`, `left bottom`                                     |
| `start`           | `start`, `start top`, `start bottom`                                  |
| `right`           | `right`, `right top`, `right bottom`                                  |
| `end`             | `end`, `end top`, `end bottom`                                        |


### Custom close
Use a button with `onPress={() => setIsOpen(false)}` to close a controlled popover. Escape and clicking outside also close it through `onOpenChange`.
<How toUse="overlays/popover/popover-custom-close" />

### Custom trigger

Use any accessible button that forwards its ref. For an avatar trigger, place `Avatar` inside `Button`, add an `aria-label`, and pass the button ref to `Popover`. Include `aria-haspopup="dialog"` and `aria-expanded={isOpen}` on the trigger.
