<PackageCommand command="npm i react-aria-components cn tailwind-variants"/>

<SourceCode toShow='sheet' />

Add the backdrop and stacking animations to your global CSS. `@theme static` keeps their keyframes available for React Aria’s swipe and stack animations.

```css
@theme static {
  --animate-sheet-backdrop: sheet-backdrop 300ms linear both;
  --animate-sheet-scale-back: sheet-scale-back 300ms ease-out both;

  @keyframes sheet-backdrop {
    from { opacity: 0; }
    to { opacity: 1; }
  }

  @keyframes sheet-scale-back {
    to { transform: translate(var(--sheet-stack-x, 0px), var(--sheet-stack-y, 0px)) scale(0.95); }
  }
}

@supports not (animation-timeline: view()) {
  .react-aria-sheet[data-has-descendants] {
    transform: translate(var(--sheet-stack-x, 0px), var(--sheet-stack-y, 0px)) scale(0.95);
  }
}
```

`sheet-backdrop` animates the backdrop opacity from `0` to `1`. React Aria uses it through `swipeAnimation` to keep the fade synchronized with the sheet’s movement.

`sheet-scale-back` scales the sheet behind to `0.95` and offsets it by `8px` toward the opposite edge. `SheetContent` sets `--sheet-stack-x` or `--sheet-stack-y` based on its position. The smaller offset keeps the close button behind the front sheet. The `@supports` rule provides the stacked appearance in browsers without view timelines.

## Anatomy
```
import { Button } from "@/components/ui/button"
import {
  Sheet,
  SheetBody,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet"
```

```
<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetContent position="right">
    <SheetHeader>
      <SheetTitle>Sheet Title</SheetTitle>
      <SheetDescription>Sheet Description</SheetDescription>
    </SheetHeader>
    <SheetBody>Sheet Body</SheetBody>
    <SheetFooter>
      <SheetClose>Cancel</SheetClose>
      <Button>Save</Button>
    </SheetFooter>
  </SheetContent>
</Sheet>
```


## Examples

### Menu
This example is like Github's profile page. You can see the sheet component is used to display the profile information.

<How toUse="overlays/sheet/sheet-menu-example" />

### Stacking

Nest a `Sheet` inside another sheet to open a new panel on top. The sheet behind moves back as the next sheet opens. Each sheet has its own close action, so closing the top sheet returns you to the previous one. This example uses three levels: workspace settings, team access, and member permissions.

<How toUse="overlays/sheet/sheet-stacking-example" />

### Controlled
You can control the open state of the sheet by using the `isOpen` prop. You can also use the `onOpenChange` prop to listen to the open state change.
<How toUse="overlays/sheet/sheet-controlled-example" />

### Positioning
Use the `position` prop to place the sheet at `bottom`, `top`, `left`, `right`, `start`, `end`, or `center`. The default is `bottom`. The `start` and `end` positions follow the text direction.

<How toUse="overlays/sheet/sheet-position-example" />

### Snap points

Set `snapPoints` to control how much of the sheet is visible at each stop. Numbers are pixels; percentages are relative to the sheet’s size. The sheet opens at the first snap point. Set an explicit height for a bottom or top sheet when using percentage snap points.

<How toUse="overlays/sheet/sheet-snap-points-example" />

### Prevent dismissal

Set `preventDismissal` to prevent closing by swiping, pressing Escape, or interacting outside. A `SheetClose` action can still close the sheet. This defaults to `true` for `role="alertdialog"`.

### Custom close
You can customize the close button by using the `SheetClose` component. This example demonstrates how to use the `SheetClose` component to create a custom close button.

<How toUse="overlays/sheet/sheet-custom-close-example" />

### Float
By default, the sheet floats with a gap from the viewport edges and rounded corners. Set `isFloat={false}` to make it sit flush against the viewport edge.
<How toUse="overlays/sheet/sheet-float-example" />

### Sticky
Use `SheetBody` for scrollable content while keeping the header and footer visible.
<How toUse="overlays/sheet/sheet-sticky-example" />
