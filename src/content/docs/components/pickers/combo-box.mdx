## Anatomy
```
import { Label } from "@/components/ui/field"
import {
  ComboBox,
  ComboBoxInput,
  ComboBoxContent,
  ComboBoxItem,
} from "@/components/ui/combo-box"
```

```
<ComboBox name="users">
  <Label>Users</Label>
  <ComboBoxInput placeholder="Select a user" />
  <ComboBoxContent>
    <ComboBoxItem>John Lennon</ComboBoxItem>
    <ComboBoxItem>Paul McCartney</ComboBoxItem>
    <ComboBoxItem>George Harrison</ComboBoxItem>
    <ComboBoxItem>Ringo Starr</ComboBoxItem>
  </ComboBoxContent>
</ComboBox>
```

### Using avatars
The combo box can be configured to display avatars instead of just regular text.
<How minW60 toUse="pickers/combo-box/combo-box-avatar-example" />

### Section
A combo box can display items grouped together in sections.
<How minW60 toUse="pickers/combo-box/combo-box-section-example" />

### Readonly
When the combo box is in a readonly state, it cannot be edited.
<How minW60 toUse="pickers/combo-box/combo-box-readonly-example" />

### Label
If the `children` of a `ComboBoxItem` is a string, the `ComboBoxLabel` will automatically wrap it. However, if you're including additional elements like an icon or avatar, you'll need to manually wrap the label, as shown below:

```
<ComboBoxItem id={item.id} textValue={item.name}>
  <Avatar src={item.image_url} />
  <ComboBoxLabel>{item.name}</ComboBoxLabel>
</ComboBoxItem>
```

### Details description
If you need to provide more information about an option, use the `ComboBoxDescription` component to display additional details.
<How minW60 toUse="pickers/combo-box/combo-box-detail-description-example" />

### Validation
If a user submits the form without selecting an item, an error message will appear.
<How minW60 toUse="pickers/combo-box/combo-box-validation-example" />

### Controlled
Control the input text with `inputValue` and `onInputChange`, or control the selected item with `selectedKey` and `onSelectionChange`.

`onInputChange` receives the input text, including text typed before an option is selected. `onSelectionChange` receives the selected item’s key.

#### Input
Pass `inputValue` and update it with `onInputChange`.
<How minW60 toUse="pickers/combo-box/combo-box-controlled-example" />

#### Selection
Pass `selectedKey` and update it with `onSelectionChange`.
<How minW60 toUse="pickers/combo-box/combo-box-controlled-selection-example" />

### Multiple select
Set `selectionMode="multiple"` to allow multi-select, and use [TagGroup](/docs/components/collections/tag-group) to display the selected items.

<How minW60 toUse="pickers/combo-box/combo-box-multi-select-example" />

### Custom value
Set `allowsCustomValue` to allow input that does not match a listed option.
<How minW60 toUse="pickers/combo-box/combo-box-custom-value-example" />

### Disabled
When the combo box is disabled, it becomes non-interactive and cannot be edited.
<How minW60 toUse="pickers/combo-box/combo-box-disabled-example" />
