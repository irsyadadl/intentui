## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/note"/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components @heroicons/react cn"/>
<SourceCode toShow='note'/>

## Anatomy
```
import { Note } from "@/components/ui/note"
```

```
<>
  <Note intent='info'>Note for info</Note>
  <Note intent='warning'>Note for warning</Note>
  <Note intent='danger'>Note for danger</Note>
  <Note intent='success'>Note for success</Note>
  <Note intent='default'>Note for default</Note>
</>
```
