## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/progress-circle"/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components cn"/>
<SourceCode toShow='progress-circle'/>

## Anatomy
```
import { ProgressCircle } from "@/components/ui/progress-circle"

<ProgressCircle aria-label="Loading…" value={25} />
```

## Examples

### Indeterminate
You can also make the progress circle indeterminate by setting the `isIndeterminate` prop.
<How toUse="statuses/progress-circle/progress-circle-indeterminate-example" />

### Custom size
Set the progress circle’s size with Tailwind CSS classes in `className` or with the `style` prop.
<How toUse="statuses/progress-circle/progress-circle-custom-size-example" />

### Controlled
You can control the progress circle by using the `value` prop.
<How toUse="statuses/progress-circle/progress-circle-controlled-example" />

### Combine with button
