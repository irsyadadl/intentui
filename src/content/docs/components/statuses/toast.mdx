## Introduction
The toast components use [Sonner](https://sonner.emilkowalski.ski/) by [Emil Kowalski](https://github.com/emilkowalski).

## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/toast"/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i sonner cn"/>

<SourceCode toShow='toast'/>

## Getting started
Put the `Toast` somewhere in your app layout to make it visible to all your components or pages.
```
import { Toast } from '@/components/ui/toast';
export default function Layout({ children }: Readonly<{ children: React.ReactNode }>) {
  return (
    <>
      <Toast />
      {children}
    </>
  );
}
```
Call `toast()` to display a notification.
```
<Button onPress={() => toast('Someone requested to delete this product')}>
  Delete
</Button>
```

### Expand
Toast can be expanded to show more content.
```tsx
<Toast expand />
```

### Hide icon
Status toasts, such as success and warning messages, display an icon by default. Hide it for an individual toast with these classes:
```tsx {2-5}
toast.success(`Copied ${text} to clipboard`, {
  classNames: {
    toast: '[&:has([data-icon])_[data-content]]:ml-0',
    icon: 'hidden'
  }
})
```

Hiding icons globally also hides the indicators used by loading and promise toasts.

### Don't close automatically

Set `duration: Infinity` to keep a toast open until the user dismisses it or selects an action.

```tsx {2}
toast('Someone requested to delete this product', {
    duration: Infinity,
    cancel: {
        label: 'Cancel',
        onClick: () => alert('Cancelled')
    },
    action: {
        label: 'Delete',
        onClick: () => alert('Deleted')
    },
})
```
