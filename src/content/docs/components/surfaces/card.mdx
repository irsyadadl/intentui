Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i cn"/>
<SourceCode toShow='card'/>

## Anatomy
```
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
```

```
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card Description</CardDescription>
    <CardAction>Card Action</CardAction>
  </CardHeader>
  <CardContent>Card Content</CardContent>
  <CardFooter>Card Footer Button</CardFooter>
</Card>
```

## Spacing

Use `--card-spacing` to control the card's vertical padding, the gap between sections, and the horizontal padding of its header, content, and footer. The default is `--spacing(6)`.

```tsx
<Card className="[--card-spacing:--spacing(4)] sm:[--card-spacing:--spacing(6)]">
  <CardHeader title="Users" />
  <CardContent>Card content</CardContent>
</Card>
```

### With table
Use `bleed` and set the table's `--gutter` to `var(--card-spacing)` to align its columns with the card's padding.
<How isCenter={false} withNoPadding toUse="surfaces/card/card-table-example"/>

For table docs, check out the [Table](/docs/components/collections/table) docs.

## Section title
Use `CardHeader` on its own with `withoutPadding` to omit the default padding.
```
<CardHeader
  title="List Daemons"
  description="List of daemons to use in your sites."
/>
```
