## Anatomy
```
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
```

```
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card Description</CardDescription>
    <CardAction>Card Action</CardAction>
  </CardHeader>
  <CardContent>Card Content</CardContent>
  <CardFooter>Card Footer Button</CardFooter>
</Card>
```

## Spacing

Use `--card-spacing` to control the card's vertical padding, the gap between sections, and the horizontal padding of its header, content, and footer. The default is `--spacing(6)`.

```tsx
<Card className="[--card-spacing:--spacing(4)] sm:[--card-spacing:--spacing(6)]">
  <CardHeader title="Users" />
  <CardContent>Card content</CardContent>
</Card>
```

## Section title
Sometimes, you may only need a card header without wrapping container itself. Of course, you need don't want the default padding, right? So I have prop called `withoutPadding` to help you out.
```
<CardHeader
  title="List Daemons"
  description="List of daemons to use in your sites."
/>
```
