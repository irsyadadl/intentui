## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/separator"/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i react-aria-components cn"/>
<SourceCode toShow='separator'/>

## Anatomy
```
import { Separator } from "@/components/ui/separator"

<Separator orientation='vertical | horizontal' />
```

## Examples

### Orientation
Separator has two orientations: `horizontal` and `vertical`. The default is `horizontal`.
