## Installation

Add the component with the CLI.
<PackageCommand command="npx shadcn@latest add @intentui/text"/>

## Manual installation

Install the dependencies, then copy the component source into your project.
<PackageCommand command="npm i cn tailwind-variants"/>
<SourceCode toShow='text'/>

## Anatomy
```
import { Text } from "@/components/ui/text"

<Text>The quick brown fox jumps over the lazy dog</Text>
```
