## Usage

Pass the numeric field to `dataKey` and the category field to `nameKey`. Use the category values as keys in `config` to provide labels and optional colors.

```tsx
<PieChart
  data={data}
  dataKey="amount"
  nameKey="name"
  config={{
    Organic: { label: "Organic" },
    Paid: { label: "Paid" },
  }}
/>
```
