## Starter kit
Use the <NewTab href="https://github.com/intentui/vite">Vite starter kit</NewTab> for a project with Intent UI configured.

## Provider and switcher
Install `@heroicons/react` for the switcher icons.
<PackageCommand command="npm i @heroicons/react"/>

Create `theme-provider.tsx` and `theme-switcher.tsx`:
<CodeBlock
    source={{
        'theme-provider.tsx': 'dark-mode/vite/theme-provider.tsx',
        'theme-switcher.tsx': 'dark-mode/vite/theme-switcher.tsx',
    }} />

## Usage
Wrap `App` with `ThemeProvider` in your Vite entry file:

```tsx {5} {9-11}
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.tsx'
import './index.css'
import { ThemeProvider } from './components/theme-provider.tsx'

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <ThemeProvider>
      <App />
    </ThemeProvider>
  </React.StrictMode>,
)
```
