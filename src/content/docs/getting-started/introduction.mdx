## Introduction
Intent UI is an open-source collection of accessible React components built with **React Aria Components** and **Tailwind CSS v4**. Use them as a starting point for your interface, then adapt their styles and behavior to your project.

The component source lives in your codebase. You can add components with the CLI or copy them manually, inspect how they work, and change them whenever you need to.

## Built on React Aria

React Aria provides the foundations for keyboard navigation, focus management, accessible interactions, and internationalization. Intent UI adds styles and component compositions so you can spend more time building your application.

## Styling and customization

Components use Tailwind CSS v4 for styling. Adjust utility classes, extend variants, or update your theme to match your design. Since you have the source, you can make changes directly without waiting for a library update.

## Getting started

Follow the [installation guide](/docs/getting-started/installation) to set up your project, then choose the components you need. The components are written in TypeScript and work with frameworks that support React.

## Blocks

[Intent UI Design](https://dub.sh/designiui) offers ready-to-use blocks for application interfaces, marketing pages, charts, and commerce. Customize them to fit your project when you need a larger starting point.

## FAQ

### Is Intent UI free and open source?

Yes. The components are free and open source.

### Can I use it in commercial projects?

Yes. You can use the components in personal and commercial projects without attribution.

### How do I add components to my project?

Use the shadcn CLI or copy the source manually. See the [installation guide](/docs/getting-started/installation) for both options.

### Can I use it outside of React?

The components are built for React and depend on React Aria Components.
