## Laravel installer
Create a project using the Laravel installer. If you need to install it first, follow the [Laravel installation guide](https://laravel.com/docs/12.x/installation#creating-a-laravel-project).
```bash
laravel new app --using=intentui/laravel
```

## Composer
Alternatively, if you're using Composer, install Intent UI with the command below:
```bash
composer create-project intentui/laravel app
```

Once installed, you can start adding components to your project by running:
<PackageCommand command="npx shadcn@latest add @intentui/table"/>

## Source code
Clone the [Laravel starter kit](https://github.com/intentui/laravel) to use its source directly.
