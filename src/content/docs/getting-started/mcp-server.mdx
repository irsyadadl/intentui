## Registry

To use the Intent UI registry, add the following entry to your `components.json`:

```json
{
  "registries": {
    "@intentui": "https://intentui.com/r/{name}"
  }
}
```

## Initialize

Choose a client and run one of the following commands:

<McpTabs/>

After initialization, use your client to browse, search, and install registry components. See the [Shadcn MCP documentation](https://ui.shadcn.com/docs/mcp?utm_source=intentui.com&utm_medium=referral&utm_campaign=docs&utm_content=%2Fdocs%2Fmcp).
