title: "TanStack Router"
description: "Set up Intent UI in a TanStack Router project with Tailwind CSS."
---

## Installation
Start a new project with the following command:
<PackageCommand command="npx create-tsrouter-app@latest app --template file-router --tailwind"/>

Next, initialize in your project:
<PackageCommand command="npx shadcn@latest init @intentui/theme-default"/>

## Adding components
Add Intent UI components to your project with the following command:
<PackageCommand command="npx shadcn@latest add @intentui/text-field @intentui/button @intentui/menu"/>

## Starter kit
Clone the [TanStack Router starter kit](https://github.com/intentui/tanstack-router) for a project with Intent UI configured.
